# F12 CI/CD and release

## Summary

Makes "zero human implementation" checkable: every push runs all gates; iOS code is built and
tested on a macOS runner; the station deploys to Azure staging; the app goes to TestFlight. No
secrets in the repo: Azure uses OIDC federated credentials, Apple and HUB keys live in GitHub
environment secrets and Key Vault.

## In scope

- `ci.yml` (ubuntu): `npm ci`, format, lint, typecheck, unit; Swift 6 Linux tests via
  `scripts/swift-test.sh`; `scripts/verify-exports.sh` on export test output.
- `ios.yml` (macos, pinned Xcode): runs on push to every branch, one job per package under
  ios/Packages plus `App`, job names equal the package name; `xcodebuild build` for iOS, `xcodebuild test` on an iOS
  simulator for App UI tests; uploads test results.
- `deploy-station.yml`: build the station API and worker image, push to Azure Container Registry,
  deploy to Container Apps `staging`, run migrations, smoke-test `/health`; `production` requires
  the GitHub environment approval.
- `testflight.yml`: archive with `xcodebuild`, export with `ios/ci/ExportOptions.plist`, upload with
  `xcrun altool` using an App Store Connect API key from environment secrets. Manual trigger only.
- Web deploys through the Vercel Git integration (documented, no workflow).
- `infra/` Bicep: Container Apps environment (api + worker apps), Postgres Flexible Server, Storage
  account with `originals` container (versioning + time-based immutability), Key Vault, ACR, Log
  Analytics; parameters for staging and production.
- Fixed resource names, used by both Bicep and the workflows: resource group `rg-chapter-capture-<env>`,
  container apps `ca-capture-api-<env>` and `ca-capture-worker-<env>`, registry `acrchaptercapture`,
  storage `stchaptercapture<env>`, Key Vault `kv-chapter-capture-<env>`, Postgres `pg-chapter-capture-<env>`.
- Branch protection settings documented in `.github/BRANCH_PROTECTION.md` (required checks: ci, ios).

## Out of scope

- Creating the Azure subscription, Apple account or GitHub org (exist already; admin step).

