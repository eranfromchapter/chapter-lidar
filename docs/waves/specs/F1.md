# F1 Package contract

## Summary

The single source of truth every other feature builds against: JSON Schemas for the capture
record, the normalized capture model, field controls, the package manifest and the verdict; the
station OpenAPI; a TypeScript package with types and validators; a Swift package with matching
Codable models; and the repo's root tooling and gate scripts. Both languages are tested against
the same example files, so the phone and the station cannot drift apart.

## In scope

- `contract/schema/*.schema.json` (JSON Schema 2020-12): `capture-record`, `capture-model`,
  `field-controls`, `manifest`, `verdict`.
- Capture model: metres, right-handed, +Y up; floors, rooms (polygon, height, label), walls, doors,
  windows, openings (each with parent wall), objects (category + oriented box), refs to mesh/depth.
- Manifest: package id, capture id, one entry per file with `path`, `role` (closed enum from the
  guide: capture_record, raw_roomplan_json, raw_depth, plan_dxf, rooms_csv, plan_pdf,
  spatial_report_pdf, plan_png, plan_svg, mesh_glb, mesh_obj, mesh_mtl, texture, point_cloud_las,
  photo, field_controls), `sha256`, `bytes`, `mime`, `generator`, `generatorVersion`, `derivedFrom`.
- Folder layout constants from the guide: Original Exports, Site Photos, Field Measurements,
  Source Register, Working Conversions, Issued Outputs (grouped by floor and capture id).
- Capture mode enum `room | floor | exterior`; photo direction `N | E | S | W`; photo subject
  `opening | cabinetry | ceiling | fixture | equipment | defect | general` (fixed by the frozen design).
- Verdict: `ready | limited | blocked`, check results, named limitations, next actions.
- `contract/openapi/station.yaml`: upload session, package registration, verdict read, project lookup.
- `contract/examples/**`: one valid and one invalid example per schema.
- `contract/ts/` npm workspace `@chapter/capture-contract` (types + Ajv validators).
- `contract/swift/` Swift package `CaptureContract` (Codable, Foundation only, builds on Linux).
- Root `package.json` devDependencies cover every root tool later gates use: typescript, eslint,
  prettier, @redocly/cli, secretlint with its recommended preset, gltf-validator. Root scripts:
  `format:check`, `lint`, `typecheck`, `test` (all workspace tests, then `scripts/swift-test.sh`).
- Root `package.json` (npm workspaces: contract/ts, fixtures/generator, station/*, web; missing workspace folders are tolerated until their feature lands), lint/format/typecheck config,
  `scripts/swift-test.sh` (runs `swift test` for every package under contract/swift and ios/Packages
  that has no `.apple-only` marker), `scripts/verify-exports.sh <dxf|pdf|preview|gltf|las> <dir>` (independent validators run in pinned
  Docker images or npm tools: ezdxf audit, qpdf + pdftotext, Pillow + xmllint, Khronos
  gltf-validator, PDAL info; exits non-zero on any error), `scripts/wait-workflow.sh <workflow> [job]` (pushes HEAD to its branch on origin, waits for the
  push-triggered run of that workflow for the HEAD commit, and exits with the result of the whole run
  or of the named job; times out after 45 minutes), `scripts/bootstrap-swift.sh` (installs the official Swift 6 Linux
  toolchain from swift.org if `swift` is missing, verifying the published checksum).

## Out of scope

- Any capture, export or station logic.

## Acceptance criteria

```yaml criteria
AC1: {text: "Every schema compiles and every valid example passes while every invalid example fails, in TypeScript", verify: "test:contract/ts/test/examples.test.ts"}
AC2: {text: "Swift CaptureContract decodes every valid example and re-encodes it to JSON equal to the original", verify: "cmd:swift test --package-path contract/swift"}
AC3: {text: "The Swift role enum and folder layout match contract/schema exactly; the test reads the schema file and fails on any missing or extra value", verify: "cmd:swift test --package-path contract/swift --filter SchemaParityTests"}
AC4: {text: "OpenAPI document is valid", verify: "cmd:npx --no-install @redocly/cli lint contract/openapi/station.yaml"}
AC5: {text: "Root gates run green on the empty workspace", verify: "cmd:npm run format:check && npm run lint && npm run typecheck && npm test"}
```

## Steps

- F1.1 Create root tooling: package.json with workspaces and gate scripts, TS/ESLint/Prettier config, .gitignore, .nvmrc, scripts/swift-test.sh and scripts/bootstrap-swift.sh.
- F1.2 Write the five JSON Schemas, the folder-layout constants and the valid/invalid examples.
- F1.3 Build the TypeScript contract package with generated types, Ajv validators and the example tests.
- F1.4 Build the Swift CaptureContract package with Codable models and round-trip tests, and write the station OpenAPI document.
