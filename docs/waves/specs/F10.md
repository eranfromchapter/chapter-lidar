# F10 Review screen (web)

## Summary

A small web app for BIM operators and PMs: find a project, open a capture package, see the
verdict and every finding, download files, and record which source was used for each modeling
decision (the guide's "record the source used for each modeling decision").

## In scope

- Next.js (App Router, TypeScript) on Vercel; Entra sign-in (Auth.js Microsoft Entra provider);
  station API called server side with the user's token. No station credentials in the browser.
- Screens: project list → package list (revision, status, outcome) → package detail (capture
  record, findings grouped by severity, next actions, file table with role, size, sha256 and
  download) → decision log (element/area, source file, decision, remaining uncertainty, next
  verification action).
- Plan PNG preview inline; 3D preview out of v1 (download the GLB instead).
- Role gating: `bim` and `admin` can download and log decisions; `capture` sees status only.
- Design v2 (Oct 21, 2026; web-review spec; artboards 2h projects, 2i project, 2j package):
  screen-review is replaced by web-review-v2 in the HUB design system: HUB tokens, the white HUB
  chapter wordmark in the sidebar, Inter 400/600 self-hosted from `web/public/brand/` (no Google
  font request), no Times on the web. Sign-in, not-found, error and configuration pages in the
  same look. The package page shows the verdict, a plan preview per floor with its orientation
  in words (compass spec §9; no arrow on the preview), the checks in the spatial report's words
  (`checkRows` of `contract/ts/src/review-text.ts`, the function the report uses), the files,
  the decision log, the capture record, the field controls, the station status and the documents
  (plan sheet "Tabloid · 1 sheet · from the phone", the station's spatial report download, pending
  until the worker has made it). The project page lists revisions with "What revision N adds",
  including a revision still on the phone.

## Out of scope

- Editing packages. 3D viewer. Client-facing views.
