# F4 Mesh and point cloud exports (iOS)

## Summary

Writes the 3D files from the raw LiDAR mesh and depth samples, on the phone: one GLB (preferred
3D source), an OBJ+MTL package (alternative), and a LAS 1.4 point cloud for ReCap. Pure Swift +
Foundation so it tests on Linux.

## In scope

- GLB 2.0: single binary, +Y up, metres, per-vertex colour from camera frames, normals, one node
  per floor, `asset.generator` = "Chapter Capture <version>". No texture images in v1.
- OBJ + MTL: same geometry, original-name companions, relative paths only, vertex colours as
  per-vertex `v x y z r g b`.
- LAS 1.4, point data record format 7 (XYZ, RGB, GPS time, intensity 0), scale 0.001 m, offsets
  at the bounding-box minimum, correct header extents and point counts, WKT absent (local
  coordinates), system identifier "Chapter Capture", generating software with version. The
  header's global encoding marks it as derived from a phone depth sensor; the manifest records
  provenance so it is never labelled raw survey data.
- Point thinning to ≤ 5 mm voxel spacing with a cap of 20 million points; mesh decimation to a
  configurable face budget (default 1.5 million) that preserves planar edges.
- Optional LAZ is out of v1 (ReCap does not list it; the guide says validate first).

## Out of scope

- Photo texturing, Gaussian splats, E57, PLY.

## Acceptance criteria

```yaml criteria
AC1: {text: "GLB files written from every synthetic fixture pass the Khronos glTF validator with zero errors", verify: "cmd:scripts/verify-exports.sh gltf ios/Packages/MeshExport/.build/test-output"}
AC2: {text: "GLB and OBJ bounding boxes match truth.json within 2 mm and are +Y up", verify: "cmd:swift test --package-path ios/Packages/MeshExport --filter GeometryTruthTests"}
AC3: {text: "OBJ references its MTL by relative path and every referenced file exists", verify: "cmd:swift test --package-path ios/Packages/MeshExport --filter OBJCompanionTests"}
AC4: {text: "LAS files pass PDAL info with header point count and extents equal to the written points", verify: "cmd:scripts/verify-exports.sh las ios/Packages/MeshExport/.build/test-output"}
AC5: {text: "Thinning keeps every 5 mm voxel represented and never exceeds the point cap", verify: "cmd:swift test --package-path ios/Packages/MeshExport --filter ThinningTests"}
AC6: {text: "Exporting the two-floor fixture completes in under 60 s on the Linux runner", verify: "cmd:swift test --package-path ios/Packages/MeshExport --filter ExportPerformanceTests"}
```
