# F2 Capture core (iOS)

## Summary

Runs the scan. Wraps Apple RoomPlan (single room and multi-room `CapturedStructure`) and ARKit
LiDAR (scene depth and scene reconstruction mesh) behind one session API, keeps the raw outputs
as originals, and converts them into the contract `CaptureModel`. Also owns the capture-record
screen (project, address, floor/area, operator, device, mode, coverage notes, omitted rooms).

## In scope

- `CaptureSession` protocol with a live implementation (RoomPlan + ARKit) and a `ReplaySession`
  that plays back a recorded fixture, so the rest of the app is testable without a device.
- Device gate: LiDAR present (`ARWorldTrackingConfiguration.supportsSceneReconstruction(.mesh)`),
  RoomPlan supported; clear message otherwise.
- Raw originals: encoded `CapturedRoom`/`CapturedStructure` JSON, ARMeshAnchor geometry, sampled
  depth points with confidence ≥ medium, camera intrinsics and poses, written unchanged.
- Adapter: RoomPlan/ARKit types → `CaptureModel` (metres, +Y up, one floor per capture). The adapter
  is split so its math (transforms, polygon extraction, opening-to-wall assignment) lives in a pure
  Swift target `CaptureModelMapping` that builds and tests on Linux.
- Capture-record form: HUB project picker (data supplied by an injected provider; F6 wires the
  station), address confirmation, floor/area label, mode, coverage notes, omitted/inaccessible
  rooms. Device, OS and app version filled automatically.
- Debug export of raw originals in the layout `fixtures/recorded/README.md` defines.
- Package carries an `.apple-only` marker only on its Apple-framework target; `CaptureModelMapping`
  runs in `scripts/swift-test.sh`.

## Out of scope

- Writing DXF/PDF/GLB/LAS (F3, F4). Photos and field controls (F5). Upload (F6).

## Steps

- F2.1 Build the pure-Swift CaptureModelMapping target (transforms, room polygons, opening-to-wall assignment) with tests on fixtures.
- F2.2 Build the CaptureSession protocol, ReplaySession, the device gate and the raw-originals writer.
- F2.3 Build the live RoomPlan + ARKit session and its adapter into CaptureModelMapping.
- F2.4 Build the capture-record form and capture screens per the frozen design, with the validation tests.
